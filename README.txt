LOGICORE WEBSITE — START HERE

FILES
- index.html: page structure and content
- style.css: responsive glassmorphism design, animation, and transitions
- script.js: quiz logic, score tracking, navigation, and team editor

HOW TO RUN IN VS CODE
1. Extract the ZIP file to a folder.
2. Open VS Code.
3. Choose File > Open Folder and select the logicore-website folder.
4. Recommended: install the "Live Server" extension by Ritwick Dey.
5. Right-click index.html and choose "Open with Live Server".
   If you do not want to install an extension, open index.html directly in a browser.

NOTES
- Internet is needed to load the Google Fonts; the rest of the site works locally.
- The quiz is a front-end demo. Scores are not saved after reloading the page.
- Team details can be edited on screen for the current session, but are not permanently saved.
- Update the project description, rules, team information, and questions to match your actual Math Fair project.
- The site is a static front-end project. A login system, online leaderboard, and database would require a backend or hosted service.
